Quick Start Guide

Figma + VS Code with AI

Use this page as a compact guide for connecting Figma to VS Code so GitHub Copilot can read design structure and help build responsive web pages from your frames.

Path A

Figma in the browser

Use the remote MCP server. No desktop app required.

Path B

Figma desktop app

Use the desktop MCP server and work from the current selection.

Common setup

  1. Verify your Figma Education plan with your @uniri.hr email and make sure your team shows the Education users only banner.
  2. In VS Code, activate Copilot Student through GitHub Education and install both GitHub Copilot extensions: GitHub Copilot and GitHub Copilot Chat.

Path A

Figma in the browser

Use the remote MCP server when you want the simplest setup and are copying links from the browser.

Set it up

  1. Press Ctrl+Shift+P in VS Code and run MCP: Open User Configuration.
  2. Paste this into mcp.json and save:
{
  "inputs": [],
  "servers": {
    "figma": {
      "url": "https://mcp.figma.com/mcp",
      "type": "http"
    }
  }
}
  1. Click Start above the figma server entry.
  2. Allow access in the browser window that opens.

Sanity check

Open Copilot Chat with Ctrl+Alt+I, switch to Agent mode, and type #get_design_context. If it autocompletes, the connection is working.

The loop

  1. In Figma, right-click the frame you want to build and choose Copy link to selection.
  2. Prompt Copilot: Get the design context for this frame and build it as a responsive HTML/CSS page in this folder: <paste link>
  3. After design updates, copy the link again and ask Copilot to re-fetch the context and update the page.
  4. Commit and push from VS Code when the page looks right.

Path B

Figma desktop app

Use the local MCP server when you prefer selecting a frame directly in the desktop app.

Set it up

  1. Install the latest Figma desktop app and open a design file.
  2. Switch to Dev Mode with the toolbar toggle or Shift+D.
  3. In the inspect panel, enable the desktop MCP server. Figma should show http://127.0.0.1:3845/mcp.
  4. In VS Code, run MCP: Add Server, choose HTTP, paste that address, and use figma-desktop as the server ID.

Sanity check

In Copilot Chat, switch to Agent mode and test #get_design_context. If it does not autocomplete, restart both Figma desktop and VS Code.

The loop

  1. Select the frame you want to build inside the Figma desktop app.
  2. Prompt Copilot: Get the design context for my current selection and build it as a responsive HTML/CSS page in this folder.
  3. After edits in Figma, re-select the frame and ask Copilot to re-fetch the context while keeping the existing structure.
  4. You can still use the link-based workflow from Path A if that fits better.

Tips for cleaner results

Name layers clearly

Use names like HeroSection and CTA-Button. Vague names like Group 47 produce messy code.

Use structure in Figma

Auto Layout, components, and variables make MCP output much more useful because the design has real semantics.

Stay in Agent mode

Ask mode will not call the MCP tools or write files, so use Agent mode for this workflow.

Keep the scope small

Build one screen at a time instead of selecting a huge canvas with many unrelated frames.
